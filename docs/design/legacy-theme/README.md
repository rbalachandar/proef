# Legacy theme (v1, "classic")

The workbench look before the Option D redesign: Inter and Tailwind greys, rounded bordered cards, teal accent on the
active nav, pill chips, tinted callouts. Kept for reference.

- `app.css`: the design tokens exactly as they were (colours, radii, fonts, both themes).
- `*-light.png`, `*-dark.png`: Today, Campaign, Program and Inbox on the sample workspace.
- Git tag `theme-v1-classic` marks the last commit with this theme in the source (`git checkout theme-v1-classic -- web/src`).
